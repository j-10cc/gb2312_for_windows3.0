# Office 源码入口

## 项目目的

提供 Word 1.1a 原始源码、Word / Excel 原版介质与中文适配代码的索引。

## 源码结构

| 内容 | 路径 |
| --- | --- |
| Word 原始源码和文档 | `external/word11a-source/tree/Word 1.1a CHM Distribution` |
| Word 合并源树 | `external/word11a-current/CASHMERE`、`OPUS` |
| 中文适配与差异 | [office-patch](../office-patch/README.md) |
| Word / Excel 原版介质 | `external/media/office/word11a`、`excel21d` |

## 编译方法

外部源码获取和放置方法见[根 README](../../../README.md#外部依赖与目录结构)。本目录提供索引；Excel、程序组及 Word 的编译命令统一见 [office-patch](../office-patch/README.md#编译方法)。
