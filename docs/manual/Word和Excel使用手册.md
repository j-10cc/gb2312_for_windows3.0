# Word 1.1a / Excel 2.1d 使用手册

## 一、安装和启动

本手册适用于本项目简体中文术语版 Windows 3.0a 和全拼输入法 2.1。先按[安装手册](安装手册.md)安装 Windows、Word 和 Excel，再进入“中文办公”程序组打开应用。

也可通过程序管理器“文件 → 运行”启动 `A:\OFFICE\WINWORD.EXE` 或 `A:\OFFICE\EXCEL.EXE`，并按实际安装目录更换路径。Excel 请使用 EXCEL.EXE 入口，保持配套 XLCORE.EXE 位于同一目录。

Word 首次启动要求填写姓名和首字母，按提示填写即可。CGA 程序图标显示 Word、Excel；VGA 显示“Word 文字处理”“Excel 电子表格”。

## 二、显示与内存

| 配置 | Windows 启动方式 | 使用建议 |
| --- | --- | --- |
| CGA / HP 200LX | `WIN /R` | 使用实模式，常规内存紧张时一次运行一个应用 |
| VGA 实模式 | `WIN /R` | 复杂文档和打印需足够内存；可拆分处理 |
| VGA 标准模式 | `WIN /S` | 需相应处理器和扩展内存 |
| VGA 386 增强模式 | `WIN /3` | 需 386 或以上处理器及配套驱动 |

CGA 不使用 `/S`、`/3`。内存不足时，先保存文件，关闭不需要的窗口或应用，再分步操作。

## 三、文件与目录

文档编码为 **GB2312**，Word 使用自身版本的 DOC 格式，Excel 使用 XLS 和独立图表 XLC，不能直接打开 DOCX、XLSX。不要通过更改扩展名转换文件格式。

建议将个人文档放在 `D:\DOCS`、`D:\SHEETS` 等独立目录，并按实际盘符调整。Word 文档链接的 TIFF 图片、Excel 工作表与 XLC 图表需一起备份和移动。

## 四、中文输入与文件名

### 拼音输入

1. 将焦点放在 Word 正文、Excel 单元格/公式栏或可编辑的文件名框。
2. 按 Ctrl+Space 开启拼音，输入无声调拼音；v 表示 ü。
3. 观察底部候选窗：空格/回车提交首选候选，数字键选择当前页实际显示的编号，- 和 = 翻到上一页/下一页。
4. 组字期间用退格修改拼音，提交后由应用的删除/退格命令编辑文字。
5. Ctrl+Space 回到英文。改变输入焦点或回到英文会清除未提交组字，先提交再点到其他位置。

输入法支持单字和词组全拼，例如 zhongwen、shurufa、yinhang、yinyue。没有所需词组时，可逐字输入；输入法不提供联想或自动纠错。完整键位见[输入法使用手册](输入法使用手册.md)。

### DOS 8.3 文件名

基名最多 **8 字节**，扩展最多 3 字节；GB2312 一个汉字占两字节。

| 名称 | 长度规则 |
| --- | --- |
| 中文办公.DOC | 四汉字，8 字节基名 |
| AB中文CD.XLS | 四个 ASCII 字母加两汉字，8 字节基名 |
| 销售表.XLS / 图表.XLC | 符合长度规则 |
| 中文办公件.DOC | 五汉字，10 字节基名，超长 |

不要使用空格、通配符 * ?、设备名 CON/PRN/AUX/NUL/COM1/LPT1 等。扩展继续用 DOC/XLS/XLC/TIF。不要把 UTF-8 或 Big5 名称字节当成 GB2312。

Office 支持合法 GB2312 短路径；配置和维护时短英文目录更方便。安装参数目录上限 70 字节。Windows Setup 目录按该介质要求使用短英文路径。

建议个人文件放在 D:\DOCS、D:\SHEETS 等独立目录。在原生“打开”框切换盘符和目录，确认高亮与名称后打开。“另存为”遇同名文件时核对覆盖提示；取消应保留旧文件。

## 五、Word 使用

### 新建、编辑、保存和重开

1. 用“文件 → 新建”创建文档，选择能显示中文的字体，例如当前字体列表的 CFShouSung，输入中文和英文。
2. 用“格式”中的字符、段落命令设置字号、粗体、缩进、对齐和段间距。检查中英文混排后的换行位置。
3. 方向键移动光标，需要替换时先选择文字；中文退格/Delete 按整字处理。复制、剪切、粘贴使用“编辑”菜单。
4. 第一次用“文件 → 另存为”保存 `D:\DOCS\中文办公.DOC`，以后用“文件 → 保存”。目标文档目录须已经存在。
5. 保存后关闭，再用“文件 → 打开”重开，检查内容、格式和文件名后继续编辑。重要文档另存一份，再做大范围修改。

查找、替换和撤销通过“编辑”菜单使用。部分操作会清除撤销记录，覆写输入后应及时检查结果；重要修改前请另存副本。

### 表格、页眉和脚注

在“插入”中建立表格，通过相应表格对话框处理行列、合并或拆分。跨页时核对下一页的行与边框，保存后重开检查。长表先做小样，确定纸型和列宽再扩展。

普通页眉页脚从“编辑”中的“页眉和页脚”进入；脚注从“插入”中的脚注命令进入。分页后核对前后页；不同页眉或页格式使用节和文档选项。编辑子文档后回正文再保存，并用预览检查分页。

### 页码、域和目录

需要时在“查看”启用完整菜单，再使用原生页码、域和目录命令。PAGE、TOC 等代码及样式名保持原语法，不翻译代码、不直接改 DOC 二进制。目录以标题样式组织正文；编辑分页后更新目录，检查目录页码与正文一致。

### 图片与链接

使用外链 TIFF 图片时，保留 DOC 引用的实际路径及图片文件；只移动 DOC 不会自动改写链接。交给其他机器时，连同全部 TIFF 和路径说明一起交付，或在 Word 内重新指定链接后另存。

例如文档引用 C:\WINDOWS\SMALL.TIF，移动 DOC 后仍须保留该图片路径，或在 Word 内重新指定图片。复制文档时请同时复制链接的图片文件。

## 六、Excel 使用

### 工作表与保存

用“文件 → 新建”建表，选择单元格输入标签或数字，已有内容通过公式栏或单元格编辑入口修改。按需要调整列宽和字体；CGA 窄列会省略放不下的完整汉字，加宽列或从公式栏核对全文。

用“文件 → 另存为”保存 `D:\SHEETS\销售表.XLS`。关闭重开，检查标签、数值和公式结果。不要把现代工作簿仅改扩展名为 XLS。减少实模式同时打开的工作表和视图；复杂工作表可拆分处理。

### 公式与中文字符串

公式保持英文函数名、原操作符与引用语法。例如 B2、C2 为数字时，`=SUM(B2:C2)` 计算合计。工作表和对象引用名称应与实际名称一致。

旧版字符串函数按字节工作：

| 公式 | 结果 |
| --- | --- |
| =LEN("中文") | 4 |
| =LEFT("中文",2) | 中 |
| =RIGHT("中文",2) | 文 |
| =MID("中文",3,2) | 文 |

不要以落在汉字中间的位置或长度截取中文。确认公式既检查显示结果，也检查引用范围；保存重开后重新计算核对。

### 区域、排序与窗口

选中完整区域后通过“编辑”菜单复制、粘贴、填充或替换。排序时将同行标签与数值一起选入，避免只排序一列而使记录错位；先另存原表副本。

多窗口、分割和冻结使用“窗口”菜单。它们可能是同一表的共享视图，修改会影响相同内容；隐藏视图不等于删除数据。打印或退出前关闭不需要的附加视图。过长文本出现编辑困难时，缩短文本或分段编辑后重试。

### 图表与 XLS/XLC 配对

选择数据后，通过原生新建图表流程创建图表，在图表菜单设置类型、标题、坐标轴和图例。工作表存为 XLS，独立图表存为 XLC。

例如 SHEET1.XLS 与 CHART.XLC 放在同一目录，先打开工作表，再开图表。源表改动后重新计算，核对图例、类别和柱值，分别保存两文件。移动与备份时请成对复制，并检查图表的数据引用。

### Note 批注

选择单元格，在“公式”中的批注/Note 命令输入或修改说明，通过信息窗口查看批注。删除时核对单元格及永久删除提示。Note 与单元格标签不同，删除批注后检查文字和公式仍保留，再保存 XLS。

## 七、打印与低内存操作

在 Windows 中配置实际打印机和端口。中文打印使用配套 CEPSON.DRV 时，请选择与实际设备相符的型号、纸张和接口。生成 PRN 文件不等于纸张已经打印。

Word 先核对纸型、方向和边距，更新 PAGE/TOC，再进入打印预览并翻至末页，检查表格、图片、页眉和脚注。打印时确认范围、份数、设备及端口；可打印区域提示需按实际纸张核对后决定是否继续。等待输出结束再关闭应用或 Windows。

Excel 先选有限打印范围，设置重复标题、分页、纸型、方向、边距与页眉页脚，检查全部预览页再打印。可由打印对话框的 Preview 选项进入预览，不使用现代 Excel 的功能区操作方式。

CGA 实模式下，先打印工作表和批注，再打印图表；必要时保存文件、退出 Windows 后重新启动，再打印下一部分。VGA 实模式处理复杂 Word 文档和打印时，应配置足够的扩展内存。内存不足先保存，再关附加视图/其他应用，重启会话后分步打印，不要重复点打印累积任务。

中文打印请使用配套打印驱动；PostScript 中文输出不在支持范围。部分 HLP 帮助内容为英文或使用其他中文术语。

## 八、重新安装和视频切换

退出 Windows，从完整介质重跑安装命令即可重新复制文件。视频参数须与 Windows 的实际配置一致；只改 Office 参数不会转换 Windows 显示驱动。

## 九、卸载和恢复

退出 Windows，在 DOS 运行：

```dos
A:\OFFPK\REMOVE A:\OFFICE
```

按实际路径替换目录。安装未完成而需要恢复时，改用 `A:\OFFPK\RECOVER A:\OFFICE`。请保留 Office 目录中的 GB30TX 备份目录，直到不再需要卸载或恢复。个人 DOC/XLS/XLC/TIFF 文件应存放在独立文档目录，并另行备份。

共享组件默认保留，需要一并恢复时附加 UNUSED。执行前先保存个人文件并退出 Windows。

Windows 系统没有独立卸载器。卸载 Office 不会删除整个 Windows 系统。

## 十、常见问题

| 现象 | 处理 |
| --- | --- |
| 提示退出 Windows | 正常保存并退出，从 DOS 运行安装/卸载/恢复，不在 Windows 的 DOS 会话安装 |
| 未知系统或驱动 | 核对基础 Setup、FINALIZE 和视频类型，不混用英文/Big5 模块 |
| Logo 后退回 DOS | HP 200LX 使用 WIN /R；必要时从完整系统介质运行 FINALIZE CGA 实际Windows目录 |
| 网络未启动提示 | 不使用网络时按提示确认；需要网络时在 Windows 中配置相应网络 |
| 中文办公组缺失 | 退出 Windows 后重跑同一路径 INSTALL；OFFGROUP.EXE 仅显示已有组 |
| Excel 入口或图标不对 | 使用安装生成的组，从 EXCEL.EXE 启动，保持配套 XLCORE.EXE，使用配套文件 |
| 拼音候选不出现 | 核对焦点、Ctrl+Space 状态和配套安装的输入法文件 |
| 名称无效或找不到 | 核对 GB2312、8.3 长度、盘符和目录，先试 中.DOC / 中.XLS |
| 图表不更新或缺图 | 核对 XLS/XLC 配对、源表引用和 DOC 中 TIFF 路径，更新并分别保存 |
| 实模式内存不足 | 保存文件、关多余视图和其他应用，重新启动后分步操作 |
| 卸载后共享文件/用户组还在 | 共享组件默认保留；确需一并恢复时退出 Windows，再使用 UNUSED 参数 |

软件和词库许可可查阅安装包中的 NOTICES、PY21DOC 目录。
