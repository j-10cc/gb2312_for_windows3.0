# Windows 3.0 全拼输入法 2.1 使用手册

全拼输入法 2.1 随 Windows 简体中文安装包提供，可在 Word 1.1a、Excel 2.1d 和支持的编辑框中输入 GB2312 中文。请按[安装手册](安装手册.md)安装系统与应用。

## 开启与关闭

将光标放在正文、单元格或可编辑的文本框中，按 **Ctrl+Space** 开启输入法。屏幕底部显示拼音输入栏和编号候选；再按 Ctrl+Space 切换回英文。

CGA 输入栏高 24 像素，VGA 高 40 像素。若普通窗口遮住输入栏，可将窗口上移或缩小。关闭输入法后，输入栏收起。

## 输入单字和词组

直接键入不带声调的全拼，`v` 表示 ü：

| 键入 | 示例候选 |
| --- | --- |
| `zhongwen` | 中文 |
| `nihao` | 你好 |
| `shurufa` | 输入法 |
| `zhongwenshurufa` | 中文输入法 |
| `zhonghuarenmingongheguo` | 中华人民共和国 |
| `gongzuobiao` | 工作表 |
| `danyuange` | 单元格 |
| `fenbianlv` | 分辨率 |
| `yinhang` | 银行 |
| `yinyue` | 音乐 |

可以输入单引号分隔音节，例如 `zhong'wen`。分隔符不用于区别同码词，`xian` 与 `xi'an` 显示相同候选。

## 选择和修改候选

| 按键 | 操作 |
| --- | --- |
| 空格、回车 | 提交当前页首选候选 |
| 数字键 | 选择当前页对应编号的候选 |
| `-`、`=` | 上一页、下一页；首尾循环 |
| 退格 | 删除一个尚未提交的输入字母或分隔符 |
| Esc | 取消尚未提交的拼音 |
| 标点 | 先提交当前页首选，再输入标点 |
| Ctrl+Space | 切换中文、英文输入 |

单字页最多显示 9 项，包含词组的页最多显示 3 项。请按屏幕上实际显示的编号选择。

在 Excel 中，提交候选后通常还需要再按一次回车完成单元格编辑。文字提交后，使用 Word 或 Excel 自身的编辑、删除、撤销命令修改。

切换到其他编辑框或应用前，请先提交拼音。未收录的全拼会按原字母输出；单次最多输入 63 个字符，超过后会先输出已输入的字母。

## 未找到所需文字时

输入法支持单字及 2～8 字的词组全拼。没有合适词组时，可拆成较短词组或逐字输入，并使用翻页键查找其他候选。输入法不提供整句自动分词、联想、自学习或自动纠错。

中文采用 GB2312 编码。文件名须满足 DOS 8.3 的字节长度限制；四个汉字已占满八字节基名。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 按键只出现英文 | 确认光标处可编辑，并按 Ctrl+Space 开启输入法 |
| 候选栏被窗口遮住 | 将窗口上移或缩小 |
| 候选没有所需词组 | 拆分词组或逐字输入，使用 `-`、`=` 翻页 |
| Excel 提交后仍处于编辑状态 | 再按一次回车完成单元格编辑 |
| 常规内存不足 | 保存文件、关闭其他应用后重试；HP 200LX 使用 `WIN /R` |

词库和字体文件应保留在安装目录，不要单独移动或删除。词库许可与来源说明可在安装后的 PY21DOC 目录查阅。
