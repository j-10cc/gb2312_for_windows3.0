# Windows 3.0 简体中文版安装手册

本安装包提供采用简体中文术语的 GB2312 Windows 3.0a、全拼输入法 2.1，以及 Word 1.1a 和 Excel 2.1d。

## 准备安装文件

准备两份安装包：

| 文件 | 内容 |
| --- | --- |
| `W30SC21.ZIP` | Windows 系统、CGA/VGA 组件和全拼输入法 2.1 |
| `GB30SC21.ZIP` | 简体中文 Word 和 Excel |

先备份已有系统和个人文件。将两份 ZIP 分别完整解压到可写目录，例如 `A:\W30`、`A:\OFFPK`。保留 ZIP 内部目录，不要将两包解压到同一目录。

以下示例将 Windows 安装到 `A:\WINDOWS`，Office 安装到 `A:\OFFICE`。按实际机器更换盘符和路径。安装介质、Windows、Office 须使用互相独立的目录；路径使用 DOS 8.3 短文件名，Windows 安装路径使用英文。盘符和父目录须已存在，并留足系统、应用、字库和备份所需的磁盘空间。

Office 安装程序支持 DOS 5.0 及以上和 8086。HP 200LX 使用 CGA 配置，并以 `WIN /R` 启动 Windows。

## 安装 Windows

退出 Windows，在 DOS 中进入系统介质目录：

```bat
A:
CD \W30
INSTALL CGA A:\WINDOWS
```

VGA 显示配置将最后一行改为：

```bat
INSTALL VGA A:\WINDOWS
```

Windows 目标须为尚不存在的新目录。在图形 Setup 中选择与命令相同的目标目录，填写用户信息并完成文件复制和程序组创建。出现未安装网络的提示时，无网络环境可选择“确定”继续。

Setup 完成后退出 Windows，等待批处理显示安装完成。如果 Setup 已完成但没有显示完成提示，在同一介质目录执行：

```bat
FINALIZE CGA A:\WINDOWS
```

VGA 使用 `FINALIZE VGA A:\WINDOWS`。FINALIZE 必须填写实际 Windows 目标目录，且要求 Setup 已完成；不能只输入 `FINALIZE CGA`。

## 启动 Windows

HP 200LX 和其他 CGA 配置使用：

```bat
A:
CD \WINDOWS
WIN /R
```

也可在 Windows 目录运行 `WINR`。CGA 使用实模式；VGA 可根据处理器、内存和驱动配置选择 `WIN /R`、`WIN /S` 或 `WIN /3`。常规内存紧张时，一次运行一个应用。

进入程序管理器后，可从“主群组”“附件”“游戏”打开程序，例如控制面板、写字板、计算器和画图。

## 安装 Word 和 Excel

保存文件并退出 Windows，进入 Office 介质目录：

```bat
A:
CD \OFFPK
INSTALL CGA A:\OFFICE A:\WINDOWS PROVISION
```

VGA 将 CGA 改为 VGA。第二个路径是 Office 目标目录，第三个路径是已经安装的 Windows 目录。完成后进入 Windows，从“中文办公”程序组启动 Word 或 Excel。

也可通过程序管理器“文件 → 运行”打开 `A:\OFFICE\WINWORD.EXE` 或 `A:\OFFICE\EXCEL.EXE`。Excel 请从 EXCEL.EXE 启动，保持配套 XLCORE.EXE 与其位于同一安装目录。

## 中文输入

在正文、单元格或编辑框中按 **Ctrl+Space** 开启拼音，输入不带声调的全拼，例如 `zhongwen`、`shurufa`、`yinhang`、`yinyue`。空格或回车提交首选候选，数字键选择当前页候选，`-`、`=` 翻页，Esc 取消组字。再按 Ctrl+Space 切换回英文。

完整键位和操作见[输入法使用手册](输入法使用手册.md)；Word 和 Excel 的文件、打印操作见[Word 和 Excel 使用手册](Word和Excel使用手册.md)。安装后的输入法说明位于 `PY21DOC\GUIDE.TXT`。

## 卸载与恢复 Office

退出 Windows，在 DOS 中运行：

```bat
A:\OFFPK\REMOVE A:\OFFICE
```

安装未完成而需要恢复安装前文件时，运行：

```bat
A:\OFFPK\RECOVER A:\OFFICE
```

共享组件默认保留。如需一并恢复共享组件，可在命令末尾附加 `UNUSED`。请保留 Office 目录中的 `GB30TX` 备份目录，直到不再需要卸载或恢复。个人 DOC、XLS、XLC、TIFF 文件建议存放在独立文档目录，并另行备份。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| HP 200LX 显示启动 Logo 后返回 DOS | 在 Windows 目录执行 `WIN /R`；确认安装时选择 CGA |
| 手动 Setup 后中文缺字或显示不全 | 退出 Windows，回完整系统介质目录执行 `FINALIZE CGA 实际Windows目录`，再以 `WIN /R` 启动 |
| CGA 图标标题末字消失，例如“画图”“游戏” | 使用 2026-10-23 修订的 CGAS12.FON；已有系统按下文替换字体 |
| 提示目标目录无效 | 使用绝对 DOS 短路径；新装 Windows 的目标目录应尚不存在，父目录和盘符应已存在 |
| 中文办公程序组缺失 | 退出 Windows，使用相同目录重跑 Office INSTALL |
| 拼音候选栏不出现 | 将光标放在可编辑位置，再按 Ctrl+Space；确认使用完整安装的系统及应用 |
| 安装较慢 | 等待文件复制完成，期间不要取出存储卡或切断电源 |
| 内存不足 | 先保存文件，关闭其他应用或多余窗口，重新启动 Windows 后分步操作 |

文档使用 GB2312 编码及 DOS 8.3 文件名。Word、Excel 使用各自版本的 DOC、XLS、XLC 格式，不能直接打开 DOCX、XLSX。移动文档时，请一并复制其链接的 TIFF 图片或配套工作表、图表。
